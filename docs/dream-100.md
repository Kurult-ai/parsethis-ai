## How to Use This List

## Outreach Playbook

1. **Build in public** — ship open-source detection tools, publish research, write technical blog posts.
2. **Engage authentically** — reply thoughtfully on threads, share genuine insights, add value.
3. **Offer free tools** — give gatekeepers something their audience will love (free tier, detection playground, compliance checklist).
4. **Sponsor strategically** — newsletters and podcasts where Parse's exact audience already listens.
5. **Co-publish research** — partner with security researchers on prompt injection, agent security, and compliance mapping papers.
6. **Never compete — complement** — every interaction should position Parse as enabling, not threatening, the gatekeeper's work.
